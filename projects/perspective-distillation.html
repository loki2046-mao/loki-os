4 个人 / 公开材料 / 隔离评测

我喜欢看的，是一个人遇到麻烦时先看什么，
最后决定留下什么。

我为什么做这个：一开始我也以为，人物 Skill 把语气学像就够了。后来越做越觉得不对：口头禅很好抄，真正难的是看清一个人在具体工作里怎么选、怎么改、什么时候停。
01 / 留住差别四个人，得保留四种不一样的看法

碰到同一个问题，他们可以先看作品、场景、人物、结构或倾听，也可以停在不同结论。

02 / 拿新题试一试给它几道没见过的题

训练材料和留出题分开。我想看判断动作还能不能用，复述原材料不算通过。

03 / 留住不知道不知道的地方，就让它说不知道

不冒充真人，不补私人动机，不把角色台词当本人，也不给尚未评测的人编一个漂亮分数。

为什么是这四个人？
当前打开的人物视角

待 v0.3 合成与回归
为什么选她进入这组实验

把复杂压力压成一个中心命题，再变成能交付的表达。

她同时穿过广告、音乐、舞台和文字。这个样本能测试：职业方法迁移到不同媒介以后，判断是否仍然是同一套，又会在哪里失效。

她先看什么作品要给谁看、入口在哪里、最后要交付什么
她会做什么先找中心句，再把压力翻译成提案、排练或版本
她拒绝什么不拿创作意图要求观众“必须看懂”
模型边界

这里整理的是公开表达和工作动作。它不负责解释性格本质；广告职业创作、歌词署名和私人经历必须分层。

我为什么会一直看她

我喜欢她把复杂事讲清楚的能力。

这些人都是我愿意反复看、反复听的人。我喜欢他们某一种表达、感觉或判断，所以想认真弄明白：那种东西到底是在什么情况下发生的。

  • 喜欢她在不同媒介里仍然保留同一套交付意识
  • 想学的是把模糊压力变成清楚中心句的方法
  • 不复制声音、外貌或私人性格

把四个人放到同一道题里

四份档案放在一起以后，
还能不能听出四个人。

我让四个子会话各自回答。每个会话只加载自己的 Skill，也看不到其他人的模型。主会话只负责传话，我想看看新问题会不会把四种判断磨成同一种答案。

刘旸把低谷改记为创作成本，刘恋把爱好与工作改成平等关系。它们自然汇流，但没有被整理成唯一答案。

这些对谈来自隔离条件下的模型演绎，不能当作真人言论。它们只用来检查差异有没有留下，也不会被包装成可传播的名人金句。
公开案例 / 证据与留出题 / 更新于 2026-08-29

我把一个人怎么做决定，
一条条从材料里捞出来。

如果只用一句话说：我想从公开材料里看清一个人在具体任务里怎么选、怎么改、什么时候拒绝。每条判断都要留下来源，训练材料和新题分开；页面里的分数，只代表这套内部测试。

我一开始以为

材料足够多，语气学得像，就能做出人物 Skill。

→
我后来才发现

口头禅很好学。真正需要留下的，是他在什么任务里先看什么、怎么改、为什么停下。

我把材料变成新题，大概走了四步事实、推断与评测分开写
01 / 找材料

先确认这句话能不能回到来源

事实、自述、观察行为、作品、他者评价和我的推断分别记录。轮到推断时，还要留下置信度和别的可能解释。

留下：sources-and-evidence 账本
02 / 写规则

把人格标签先放到一边

我记录任务、角色、阶段、入口信号、修改动作、停手条件和未知领域，尽量看一个人在具体情境里怎么做。

留下：各人物独立 SKILL.md 与 research/
03 / 出新题

训练材料和留出题分开放

评测题不会提前塞进被测 Skill；四个人物也彼此独立加载，免得最后都答成同一种声音。

留下：evals/ 与跨人物对谈记录
04 / 留边界

答错和“不知道”都要留下

不冒充真人、不补私人动机、不把角色台词当本人，也不给尚未评测的人补漂亮分数。

当前：研究型工作模型，内部评测
四个人，四个入口

他们碰到问题时，
第一眼看的地方并不一样。

页面只使用公开材料的脱敏整理与项目内部证据。人物本人没有参与、认可或授权本项目；模型演绎也不代表真人言论。

我已经做到的

材料和题目各自有位置

  • 人物材料、Skill 与评测目录独立保存
  • 证据、自述、观察和推断分级
  • 训练与留出隔离
  • 记录内容分、格式分与硬失败

  • 36/42 对应刘旸 v0.4 新鲜留出
  • 32/36 对应鲁豫 v0.1 修正口径
  • 这些分数只代表项目内部测试
我不会拿它来声称的事

这些边界还在

  • 不代表人物本人认可或参与
  • 不证明私人动机或稳定人格
  • Papi酱当前未盲测
  • 内部评测不能当作第三方产品准确率

我只是想看看，平时读人、看材料、抓细节的能力，能不能真的做成一套可以检查的东西。
