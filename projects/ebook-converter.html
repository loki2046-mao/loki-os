Loki ebook converter / macOS + Windows

我只想换个格式，
结果先要学会怎么用 Calibre。

前段时间我又碰到这个问题：书已经在手里了，转换之前却要先装工具、找窗口、记命令。功能都在，入口还是太远。

所以我把那套转换能力包进桌面应用。使用时只管文件从哪里来、想变成什么格式，后面的复杂步骤交给产品。
看我解决了什么 Release v1.1.2（已复核）↗
01 / WHY I MADE IT

Calibre 的能力留下，
复杂步骤收进产品里面。

01

拖进去就能开始

支持单个或批量拖入 EPUB、MOBI、PDF、AZW3、DOCX、TXT 等文件，不要求用户先理解转换引擎。

02

桌面应用自己带着能力走

macOS 版本把完整 Calibre 运行时一起打包；日常使用不需要终端，也不会突然弹出另一个复杂界面。

03

原文件永远留着

输出目录、总进度、当前任务与完成结果都可见；转换不会删除原文件，完成后可以直接打开所在位置。

02 / USER JOURNEY

拖入、选择、等待，
结果出来后直接打开。

拖入

一个文件，或一整批书。

选择

目标格式与输出位置。

等待

同时看见总进度与当前文件。

打开

结果列表直接带你去成品。

03 / THE HARD PART

真正难的，是让它在两套系统里都像普通软件。

1.1.2macOS universal
1.1.1Windows x64
6+常用输入格式
0日常命令行步骤
TAKEAWAY

有些工具功能都在，问题是普通人根本不想先学半天。

我保留 Calibre 的转换能力，只让用户看见拖入文件、选格式、看进度和打开结果。Release 页面与 universal DMG 资产记录已复核；本轮未下载或安装 DMG。
