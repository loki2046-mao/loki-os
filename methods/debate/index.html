01 设计文档先给素材定价值

2026-04 的设计文档里有一张分级表：真实辩题加交锋记录值五星，因为有来回攻防和取舍轨迹；某人的观点汇总只值一星，因为只有结论，没有推导痕迹。这张表决定了后面所有蒸馏往哪条路走。

02 五层操作体系长成六层

设计文档里是切入角度、立论、攻防、结变、价值收束五层；发布版 README 变成六层，中间多了【逻辑路径】一层。压力下怎么组织理由，我觉得值得单拎出来成为一步。

03 陪练模式反过来做

拆解模式直接给完整报告；陪练模式不给答案只追问：你排除了哪些切入？前提确认成立吗？必须在两个里放弃一个，你放哪个？原则写死在文档里：遇到模糊回答就继续追问，让用户自己推完。

04 引用的理论全部署名

图尔明论证模型、Paul-Elder 批判性思维框架、英国议会制赛制结构，README 列出参考书目并注明出处。引用公开理论不等于不原创，但一笔一笔说清楚是底线。
