制作手册

反复做过的事，慢慢留下方法。先挑一个你现在用得上的。

图像与视觉

电影字报生成器 ↗

给我一个主题，我照它做一张电影字报：要摄影质感，字体排版要重，视觉焦点只留一个。

一直在用

Loki 社交卡片 ↗

同一篇文章，我重新排成小红书图文、公众号封面对，还有那种带证据的知识卡片。

已经做成正式 Skill

多形态视觉系统 ↗

参考图我都给了，只换个颜色当然不够。我想看它怎么用那些图里的构图、字体和材质，做出几个真不一样的方向。

已经做成正式 Skill

封面设计系统 ↗

我做封面时，会先想这篇到底有什么值得点开，再让标题、小熊猫的动作和画面一起把这件事讲清楚。

一直在用

生图套件 ↗

只说【有电影感】太模糊了。我会把画面里有什么、字放哪儿、用什么比例写清楚，再拿去生图。

一直在用

前端幻灯片 ↗

幻灯片我直接用网页做，页面打开就能演示，排版、动效、内容都在同一个文件里，边讲边改。

一直在用

写作与表达

Loki 写作助手 ↗

它先读我发过的文章和手头的真实材料，学我说话的语气，再把我脑子里那堆碎想法整理成还像我说的话。

已经做成正式 Skill

公众号选题与大纲 ↗

脑子里有个想法，但还没想清楚从哪儿讲，我就先让它列几个选题。挑中一个，再往下写大纲。

已经做成正式 Skill

深夜清醒 Writer ↗

我在 Obsidian 里写稿，也要发公众号，就想让同一份稿子搬过去以后，颜色和段落还能留住。

已经做成正式 Skill

公众号排版 ↗

正文写好了，我只把它理出能直接复制发布的节奏、层级和重点，不重写一遍。

一直在用

微信标题生成 ↗

标题我只从文章里真正的冲突和信息差里找，不靠夸张词骗一个点击。

一直在用

飞书转公众号 ↗

飞书里写好的成稿，我让它带着结构直接搬进公众号，省掉一遍遍清格式、重排。

一直在用

阅读与判断

洞见型拆书 ↗

我让 Cola 拆书，想先看懂这本书在讲什么，再挑出值得多想的地方。材料没读全就说清楚，不能只给我一串金句。

本地 Skill，v2

阅读笔记整理 ↗

优先保留自己的划线、反对和疑问，再整理成以后真的会回来看的笔记。

已经做成正式 Skill

工作判断蒸馏 ↗

我从一个人反复修改、拒绝和选择里，找他的稳定判断，再拿没见过的新问题去试，看它会不会走样。

已经做成正式 Skill

辩论思维提取 ↗

一段争论里，我把双方各自的前提、真正的分歧，还有还没人回答的问题拆出来。

一直在用

构建与工具

个人主题系统 ↗

从 Codex 的主题恢复，到 Loki Hub、Loki Assistant 和 Cola 上的换肤，我把组件、偏好记忆和恢复方式分别理了一遍。

本地主题方法 / 另有开源主题包

工作经验蒸馏成 Skill ↗

每次改稿、改方案，我都说了不少为什么。下次还得从头教太麻烦了，我就把这些修改和理由整理成 Skill，再拿新任务试。

一直在用

电子书转换工作流 ↗

一批电子书拖进去，选好格式，转完能找到文件；哪本失败了也告诉我，别只留一个转圈。

跟着作品一起

个人创作

赛博小熊猫 Loki ↗

卡片、演示、工具里都有我的小熊猫。讲的内容不一样，它也得换动作，但看起来还得是同一只。

一直在用

歌词答案书构建 ↗

从喜欢出发，材料我自己筛，版权边界我先划好，再把挑出来的短句做成抽签和卡片。

跟着作品一起

每日拼贴诗 ↗

当天留下来的词句和情绪，我重新拼一拼，留成一小块只属于那天的文本。

一直在用
