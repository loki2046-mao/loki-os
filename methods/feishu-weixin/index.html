THE MAKING OF

从文档到排版，中间别丢掉结构。

稿子在飞书里写好了，搬到公众号还要清格式、配封面、检查一遍。我用八个脚本把这些步骤串起来，每步留下文件，出错时好找回去。

01 管线按段拆开，各自留痕

extract_public_feishu_doc.py 负责取文档，feishu_to_copy_page.py 做 wiki/docx token 解析、block 遍历、图片下载和 callout 精确提取，后面跟着复制页生成与 publish_to_wechat.py。段落、标题、提示块和图组各自成块，不把整个页面原样搬进公众号。

02 自动排版链路已经跑通

refine_text_blocks → promote_heading_blocks → auto_layout_blocks → group_images_to_gallery → ensure_intro_card，这条链在 Python 引擎里跑通了；重点词句高亮和小标题识别我都要它带上前后文语境判断，不靠正则硬扫。

03 复制页单独交付，发布前先校验

原文、预览和复制页我分开保存，最后给一个直接复制富文本的入口，省去在展示页里反复选中；validate_gzh_html.py 在发布动作前先过一遍 HTML 校验。自动规则处理完之后，人还能把不合适的地方改回来。

04 2026-07-05 的自包含化

CHANGELOG 记录这批脚本从旧工作目录迁进 loki-wechat-pipeline 的 scripts/wechat-direct-publish/，其中六个文件的路径 ROOT 从硬编码改成按脚本自身位置相对定位，迁移本身也不能把路径弄丢。

loki-wechat-pipeline/scripts + CHANGELOG
