THE MAKING OF

把一句风格感觉，写成能画的东西。

有电影感、大胆一点，这么说还不够。我把这项能力写成了带输入协议的方法：先问清楚要什么，再写能直接生成的提示词。它受过的一次最完整的压力测试，是用小熊猫 IP 连跑二十种视觉语言的海报实验。

01 先问清楚，再动笔

输入协议固定收这几样：任务类型（image / poster / character / toy / ui）、模型与比例、最多三个风格词、默认输出 safe / bold / extreme 三条、禁忌项。缺字段我就先追问；赶时间用默认值，也得显式标出来。

02 依赖外部事实就先搜索

碰到时效、IP、热点必须先搜再写，输出前给一张已核验事实清单；搜不了就明说，请用户给参考，不许按猜测编。中文上字必须逐字写死，还要求 4K 以上清晰可读，禁止文案自拟。

03 二十张海报实验是一次压力测试

我拿小熊猫 IP 跑了二十种视觉语言：瑞士国际主义、昭和复古广告、Brutalist、90 年代 Zine 复印质感、Risograph 三层套色、Bauhaus 摄影装置……每条提示词逐字存档，二十张成品图全部保存在本机。

04 失效边界写得比成功路径还硬

这三条我划得很硬：不做对在世艺术家的直接临摹指令，搜索不可用就必须停下来向用户要参考，等于说清了它什么时候不能信。
