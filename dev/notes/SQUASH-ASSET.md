# 壁球页角插画

仅本地原型。2026-09-09 使用内置 imagegen，身份参考 `../lettering-study/assets/loki.jpg`。输出 `assets/panda-squash-frames.png`。

提示词：为 Loki 个人场刊壁球交互绘制精致 3D 小熊猫动作精灵图，横向 3:1 高清，三个等宽正方形，固定摄影机与明亮薄荷色壁球场、浅木地板、粉色场线。保留橙色毛绒、白眉白脸、橙色护目镜、黑夹克、条纹尾巴，运动鞋，无咖啡耳机。右下部单只小熊猫持完整椭圆壁球拍，蓄力、击球、随挥三姿态，不要网、文字、球或轨迹。细腻毛绒与收藏玩具广告质感，亮色不暗黄。

生成结果首帧含多余黑点，未用于界面。交互使用第二、三帧的挥拍姿态，通过 CSS 逐帧切换；球和撞墙反馈独立运动。这是短帧插画交互，不是骨骼动画或视频。没有整图旋转冒充挥拍。

测试：`node qa-squash.cjs`，1440×900 / 390×844，正常及减少动态模式，图片解码、重复点击、收起重开、横向溢出和控制台。
