# 首页入场记录

首页主视觉下方、三个导航入口上方展示今日 UV/PV、累计 UV/PV。参考小山学堂首页首屏后的统计条：https://xueai.miyang.cn/slides/home.html 。

## 统计口径

- PV：打开页面、刷新，以及 hash 路由变化各计一次。同一路由重复事件不计；切换浏览器标签页只读最新统计，不增加 PV。
- UV：通过服务端设置的随机匿名 Cookie 区分浏览器；今日按 Asia/Shanghai 去重，累计独立去重，绝不将每日 UV 相加。更换浏览器或清除 Cookie 可能视为新访客。
- 今日自然日按北京时间，累计从本服务开始接收访问时起算。未导入线上历史数据。
- 本地预览明确标注「本地预览统计」。正式环境需部署同源统计服务并返回正式 scope，不能将这份本地 SQLite 数据冒充线上流量。
- 无 SDK 或第三方数据发送；请求无需提交当前 URL、姓名、设备信息。数据库仅保存随机标识的 SHA-256、日期及浏览计数。Cookie 为 HttpOnly/SameSite=Lax，保留一年。没有防机器人分析，PV 也包含真实打开网页的自动化访问。
- 请求失败显示「统计暂不可用」及 —，不伪造数值。

## 本地启动

从项目根目录运行 `python3 program-book/preview-server.py --port <预览端口>`。当前本地预览沿用已核实的 54897 端口。

数据库为 `program-book/.local/visits.sqlite3`，重启持久保存。服务拒绝直接读取隐藏路径。该目录是运行数据，不应加入公开发布文件。

`GET /api/visits` 读取；带 `X-Loki-Visit: 1` 的同源空体 `POST /api/visits` 计数并读取。前端请求排队以避免首次 Cookie 创建时并发重复访客。跨域写入被拒绝。
