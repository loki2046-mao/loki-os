# 本轮校正与细化

- 用户明确校正：Vibe coder；壁球。已修正当前场刊介绍和身份卡，壁球交互改为球碰前墙后反弹，没有球门和进球叙述。
- 桌面目录收窄、收紧，并在阅读时停留；不再跟着长内容拉伸成整列橙色空白。手机继续使用紧凑四入口。
- 制作内页保留抽拉。新增页眉、三步使用路线、实际产物侧记、来源与边界折页及页尾收回。作品背页的记录与边界也有独立层级。
- 页角物件改为带墙面与球拍的壁球场、带杯口/茶叶/液面的茶杯、带舞台灯位和观众的现场插画。插画是本站手绘矢量/样式，不是用户现场照片。未加入未授权音乐、虚构观演经历或运动成绩。
- 仅本地 program-book 修改，不改线上、产品主题与公开核验状态。
