BOX A / SUMMER 2005 / PUBLIC MEMORY

那一年，喜欢会走上街头。

李宇春、周笔畅和 2005 年的超级女声，给我留下了冠亚军名单，也留下电视直播、手机短信、街头拉票和城市里真实出现的人。一次选秀，成了许多人共同参与的现场。

2005.08.25—08.26想唱就唱
街头拉票记忆关键词：李宇春 · 周笔畅 · 万人空巷
一张怀旧海报装不下那一代人的参与方式。
01 / THE STREET

决赛前一天

杭州、长沙、昆明等地的歌迷走上街头，为喜欢的选手解释、拉票，甚至帮路人完成短信投票。

02 / THE NIGHT

八百多万张选择

8 月 26 日总决赛，李宇春获得 3,528,308 票，周笔畅获得 3,270,840 票。数字背后，是电视时代少见的全民参与。

03 / WHY IT STAYS

记住的是现场感

这一格把“喜欢”保存为一种行动：人们会制作衣服、举起画板、站到街头，让自己的选择被看见。

公开资料参考：新华社 / 搜狐 2005 街头拉票图集 ↗ · 总决赛结果 ↗

BOX C / LIVE REGISTER

我记歌，也记万人一起唱的那一秒。

五月天、张学友、杨千嬅、莫文蔚、林忆莲。这个包厢记的是我的现场：谁真的在场、哪一次合唱留了下来、后来又为什么值得重看。
